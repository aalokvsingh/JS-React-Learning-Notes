# 💼 Accenture Interview Experience: Senior Frontend Developer

This document details the questions and topics covered during my interview process for the **Senior Frontend Developer** role at Accenture.

The interview was highly focused on core JavaScript fundamentals, modern React concepts, performance optimization, and practical Git usage in a production environment.

---

## 📅 Round 1: Skill Interview (1 Hour+)

The first round was a deep dive into technical skills, covering JavaScript, React, and Git.

### 💻 JavaScript (Core Concepts & Output-Based)

This section tested fundamental knowledge and the ability to predict code execution.

* **Variables & Scope:**
    * Difference between `var`, `let`, and `const` (with detailed scope explanation).
* **Execution Context:**
    * What is **hoisting**, and how does it work internally in the JavaScript engine?
    * What is the **Temporal Dead Zone (TDZ)**?
* **Type Coercion:**
    * Difference between the equality operators `==` and `===`.
* **Functional Programming:**
    * What is a **closure**, and how does it retain access to its lexical scope?
* **Asynchronous JavaScript:**
    * Explain **callback hell**, and detail how **Promises** or `async/await` solve this issue.
    * What is the **event loop**, and how does it handle asynchronous tasks (microtasks vs. macrotasks)?
    * Difference between synchronous and asynchronous functions.
* **Output-Based Questions:**
    * Practical questions involving predicting output for scenarios related to closures, TDZ, shadowing, and hoisting.

### ⚛️ React (Scenario-Based Deep Dive)

The React portion was primarily scenario-based, focusing on practical implementation, optimization, and state management strategies.

| Topic | Key Questions & Scenarios |
| :--- | :--- |
| **Forms & Data** | How do you handle forms and manage form state efficiently (e.g., controlled vs. uncontrolled components)? |
| **API Integration** | How do you integrate APIs and manage the associated **loading**, **success**, and **error** states? |
| **Hooks** | Why is `fetch` or API calls commonly performed inside `useEffect`? |
| **Hook Fundamentals** | Explain the core React Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`). |
| **State Management** | Explain state management approaches in React (local, prop drilling, global). |
| **Global State** | Difference between **Context API** vs. **Redux** (when to use which). |
| **Prop Management** | What is **props drilling**, and how do you effectively solve it? |
| **Performance** | How can you optimize performance in large-scale React applications? |
| **Loading Optimization** | If a homepage takes 5 seconds to load, what specific techniques would you use to reduce this time? |
| **Rendering Control** | How do you prevent unnecessary re-renders in functional components? |
| **List Rendering** | Why are **keys** important when rendering lists, and what issues arise without them? |
| **Core Concepts** | Explain the React lifecycle. |
| **Reconciliation** | What is the **Virtual DOM**, and how does the reconciliation process work internally? |
| **Error Handling** | How do you handle API errors and implement efficient retries? |
| **Routing** | Explain **React Router**, covering relative vs. absolute paths, and navigation use cases. |

### 🧩 Git (Important Production-Level Commands)

This section focused on practical, real-world Git operations and safety in a production environment.

* **Commit Reversal:**
    * What is the command to safely **revert a commit** that has already been pushed to the remote repository?
* **Production Safety:**
    * Strategies for safely switching branches or handling **merge conflicts** when working directly in a production branch.
